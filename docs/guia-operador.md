# Guia do Operador — Módulos PWA

Este guia é para **operadores de campo** que usam o sistema pelo celular durante o evento.

Linguagem simples — siga o passo a passo.

---

## Como Acessar

1. Você vai receber um **link por WhatsApp** do coordenador do evento
2. Clique no link — ele abre no navegador do celular
3. Faça login com o **email e senha** que você recebeu por email
4. O sistema abre **automaticamente** no seu módulo de trabalho
5. Pronto! Você já pode começar a trabalhar

> **Dica**: Salve o link nos favoritos do navegador para acessar mais rápido da próxima vez.

---

## Módulo Transporte

Se você é motorista ou coordenador de transporte:

### Ver Viagens
- Na tela inicial, veja a lista de viagens do dia
- Cada viagem mostra: rota, horário, veículo, total de passageiros

### Embarcar Passageiros
1. Toque em **Scan QR** para abrir a câmera
2. Aponte para o QR Code da credencial do participante
3. O sistema confirma o embarque com uma vibração
4. Se a câmera não funcionar, toque em **Digitar Código** e digite manualmente

### Confirmar Embarque
- Após embarcar todos, a lista mostra quem embarcou ✅ e quem falta ⏳

---

## Módulo Alimentação

Se você trabalha no refeitório:

### Registrar Consumo de Refeição
1. Toque em **Scan QR** para abrir a câmera
2. Escaneie o QR Code da credencial do participante
3. O sistema registra a refeição automaticamente
4. Se a pessoa já comeu nesta janela, o sistema **bloqueia** e avisa

### Janelas de Refeição
- Na tela inicial, veja qual refeição está ativa agora (café, almoço, jantar)
- Fora do horário, o sistema avisa que não há janela ativa

### Busca Manual
- Se o QR não funcionar, toque em **Buscar** e digite o nome do participante

---

## Módulo Alojamento

Se você trabalha na hospedagem:

### Fazer Check-in
1. Toque em **Scan QR** para abrir a câmera
2. Escaneie o QR Code da credencial
3. Selecione o quarto/unidade para alocar
4. Confirme o check-in

### Check-out
- Na lista de ocupação, localize a pessoa e toque em **Check-out**

### Registrar Incidentes
1. Toque em **Incidentes → Novo**
2. Descreva o problema (ex: "Chuveiro com defeito no quarto 203")
3. Salve — o coordenador será notificado

## Módulo Coordenação Técnica

Se você é coordenador técnico:

- **Agenda**: veja as partidas do dia por hora e local
- **Partidas**: acompanhe status (agendada, em andamento, finalizada)
- **Resultados**: veja resultados lançados e validados
- **Estatísticas**: visão geral do progresso da competição

---

## Módulo Delegação

Se você é chefe de delegação:

- **Participantes**: veja todos os membros da sua delegação
- **Agenda**: partidas e compromissos da delegação
- **Logística**: informações de transporte, alimentação e alojamento
- **Locais**: onde estão os ginásios e quadras

## Ao Vivo (Público)

- Acesse o link público compartilhado pelo evento
- Veja placares atualizados em tempo real

## Problemas Comuns

| Problema | O que fazer |
|----------|-------------|
| **Não consigo fazer login** | Verifique email e senha com o coordenador. Se esqueceu a senha, peça para reenviar o convite |
| **Câmera não abre** | Permita acesso à câmera nas configurações do celular: Android → Configurações → Apps → Chrome → Permissões → Câmera |
| **Link expirado** | Peça um novo link para o coordenador |
| **"Acesso negado"** | Você não tem permissão para este módulo. Peça ao coordenador para verificar seu perfil |
| **QR Code não lê** | Tente aproximar ou afastar o celular. Se não funcionar, use "Digitar Código" manualmente |
| **Tela travou** | Feche e abra o navegador novamente. Se persistir, limpe o cache |
| **Sem internet** | Alguns módulos funcionam offline. Quando voltar a internet, os dados sincronizam automaticamente |

## Trocar Etapa ou Evento de Trabalho

Se você precisar trocar de etapa (mudança de sede ou etapa encerrada):

1. Toque no **nome da etapa** (ex: "Capital - 1ª Etapa") que aparece no topo da tela.
2. Alternativamente, toque no botão de menu no canto inferior direito e selecione **"Trocar Etapa"**.
3. Selecione o novo Evento e a nova Etapa.
4. **Importante:** Se você tiver dados offline pendentes (contagem no botão "Sync"), o sistema **não permitirá** a troca. Sincronize todos os dados antes de prosseguir.
5. Confirme a troca — o sistema recarrega com os novos dados.
