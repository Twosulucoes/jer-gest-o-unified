### 5.5 VOLEIBOL

| Atributo | Valor |
|---|---|
| Confederação | CBV — Regras FIVB |
| Família | sets |
| Formato | GP+SE |
| Formato da partida — Fase Classificatória | Melhor de 2 sets (25 pts, vant. 2); tie-break: 1 set de 15 pts |
| Formato da partida — Fase Final | Melhor de 5 sets (25 pts sets 1–4, 15 pts set 5, vant. 2) |
| Pontuação fase de grupos — Vitória 3×0 ou 3×1 | 3 pts vencedor · 0 pts perdedor |
| Pontuação fase de grupos — Vitória 3×2 | 2 pts vencedor · 1 pt perdedor |
| Pontuação fase de grupos — Vitória 2×0 (classif.) | 2 pts vencedor · 0 pts perdedor |
| Pontuação fase de grupos — Vitória 2×1 (classif.) | 2 pts vencedor · 1 pt perdedor |
| W.O. | 2 × 0 (25×0 / 25×0) na classificatória; 3 × 0 (25×0 / 25×0 / 25×0) na final |
| Equipe com menos de 6 atletas | Derrota por 2×0 (25×0 / 25×0) — não exclui da competição |
| Altura rede 12–14 | 2,10m (fem.) · 2,24m (masc.) |
| Altura rede 15–17 | 2,24m (fem.) · 2,43m (masc.) |
| Distribuição de chaves (24 equipes) | 8 grupos × 3 equipes, 2 melhores de cada classificam |
| Oitavas de final | 1ºA×2ºH, 1ºH×2ºA, 1ºB×2ºG, 1ºG×2ºB, 1ºC×2ºF, 1ºF×2ºC, 1ºD×2ºE, 1ºE×2ºD |
| Quartas/Semis | MIT (Melhor Índice Técnico) |

**Desempate fase de grupos (ordem):**
1. Pontos na tabela
2. Quociente de sets (sets vencidos ÷ sets perdidos)
3. Quociente de pontos (pontos marcados ÷ pontos sofridos)
4. Confronto direto (repetir critérios 2 e 3 entre empatados)
5. Sorteio

**Regra especial:** Equipe que não perde nenhum set/ponto é classificada automaticamente pelo critério de average (impossível divisão por zero).

### 5.6 VÔLEI DE PRAIA

| Atributo | Valor |
|---|---|
| Confederação | CBV — Regras FIVB Beach |
| Família | sets |
| Formato | RR (fase inicial) + SE |
| Formato da partida | Melhor de 3 sets |
| Sets 1–2 | Até 21 pontos (vantagem de 2) |
| Set 3 (decisivo) | Até 15 pontos (vantagem de 2) |
| Inscrição por escola | 2 a 4 atletas (1 a 2 duplas) por gênero |
| Pontuação | Vitória 2×0: 3 pts · Vitória 2×1: 2 pts · Derrota 1×2: 1 pt · Derrota 0×2: 0 pt |
| Altura rede 12–14 | 2,20m (fem.) · 2,35m (masc.) |
| Altura rede 15–17 | 2,24m (fem.) · 2,43m (masc.) |

**Regras de W.O. e desistência (detalhadas):**
- Dupla presente mas impossibilitada por contusão: vencedora 2 pts, perdedora 1 pt; placar 2×0 (21×0 / 21×0)
- Dupla não comparece: vencedora 2 pts, perdedora 0 pts; placar 2×0 (21×0 / 21×0)
- Desistência durante partida: sets concluídos mantêm placar real; sets não disputados = 21×0 para vencedor

**Desempate (ordem):**
1. Quociente de sets
2. Quociente de pontos
3. Sorteio

**Classificação:**
- 12–14 anos: modalidade coletiva (duplas representando escola)
- 15–17 anos: modalidade individual (duplas como unidade individual)
